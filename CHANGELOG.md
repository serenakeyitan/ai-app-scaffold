# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] — 2026-03-27

### Added
- `ai-scaffold new` command: scaffold a production-ready AI app with one command
- Support for AI providers: OpenAI, Anthropic, Gemini
- Support for auth providers: Clerk, Auth0, Supabase Auth, NextAuth
- Support for database providers: Supabase, PlanetScale, Neon, SQLite
- Support for payment providers: Stripe, Lemon Squeezy
- `ai-scaffold list-providers` command: list all supported providers
- `ai-scaffold doctor` command: check environment dependencies
- `ai-scaffold add` command: add features to existing projects
- Interactive mode with guided prompts
- Generated projects include FastAPI app, SQLAlchemy models, Docker, CI/CD
- Monitoring via Sentry (optional)
- Fully typed with mypy-compatible type hints
